# 東京大学運動会ラグビー部 公式サイト（再構築版）

`turfc.com` の構成再設計案（6系統＋お問い合わせ）に沿って作ったサイトです。表示内容はすべて入力シート（xlsx／Googleスプレッドシート）から作られます。

## ファイル構成

| パス | 内容 |
|---|---|
| `index.html` | サイト本体（画面・機能のコード。約90KB） |
| `data.js` | 入力シートから作ったサイトデータ（`tools/build_data.py` で自動生成。直接編集しない） |
| `img/` | 部章・ヒーロー写真・部員写真・パートナーロゴ・グッズ写真 |
| `tools/build_data.py` | 入力シートの表記ゆれを補正し，`data.js` を作り直すスクリプト |

入力シート（xlsx）は部員名簿を含むため，このリポジトリには置きません（`.gitignore` で除外）。部内のドライブで管理してください。

`index.html` をブラウザで開けば動きます（サーバー不要）。公開時は `turfc-site/` フォルダごと置きます。

## 更新のしかた

```bash
python3 tools/build_data.py ~/入力シート.xlsx ~/入力シート_補正済み.xlsx data.js data.js
```

1つ目が入力（リポジトリの外に置いたxlsx），2つ目が補正後のxlsx（修正ログ付き），3つ目が書き出す `data.js`，4つ目は画像対応表の読み込み元（今の `data.js`）です。補正済みのシートにもう一度かけても変更は0件です。
サイトの「サイトの更新」ページでxlsxを選ぶと，そのブラウザだけで表示を確かめられます（`data.js` を作り直すと自動で破棄されます）。

## v6からの主な修正

### データ（入力シート v14 → v15）
- **出場メンバーの氏名に学年・得点が混入**していた485件（例：`武村 晋(4) [ 1T 1G ]`）を，氏名・学年（当時）・T/G/PG/DG の各列に分離（得点528件を転記）。出身校が混入していた11件も削除。
- 全角／半角の表記ゆれを統一：相手校（`東北大学Ａ`／`東北大学A` など）が別チームとして集計されていた問題を解消。チーム（`Ｂ`→`B`），学年（`１`→`1`，`Ｍ２`→`M2`），会場（`駒場Ｇ`→`駒場G`，`へボンフィールド`→`ヘボンフィールド`），大会名（`国公立一回戦`・`国公立大会 １回戦`→`国公立大会 一回戦`）。

### サイト
- **受験生応援企画が10本表示されていなかった**（執筆者IDが空の記事を必須項目チェックで除外していた）→ 表示するよう修正（68本→78本）。執筆者不明の記事は「部員」と表示。
- 創部年数の誤り：2026年度を「創部105年目」としていた → 「創部105年・第106シーズン」（歴代表の「第106回」と一致）。基準を閲覧日の西暦から設定シートの「今季」に変更。百年史側だけにある年度の「回」の計算誤り（`西暦−1917`）も修正。
- 日付表記の混在（`2026.12/6（日）`）を `2026年12月6日（日）` に統一。
- 試合ページの成績カードと大会ボタンで勝敗数が食い違っていた（Aチームのみと全チーム）→ 大会ごとのカードに一本化し，Aチームか全試合かを明記。各カードから大会一覧へ移動できるように。
- 対戦成績の枠が崩れていた（数値が折り返す）→ 統計表示を作り直し。旧サイト表記の対戦成績が複数行ある場合もすべて表示。
- スマホで表のラベルが出ていなかった → 自動で付与。試合一覧の表はスマホでは「日付・相手・結果」を1行に収める表示に。
- ダークモードで年表の本文が読めなかった（未定義の色変数）を修正。パートナーのロゴを同じ大きさの枠に揃え，ロゴのない社名が二重に出ていたのを修正。
- 【要確認】の文が公開ページに出ていた（グッズ説明・練習曜日・新歓日程・協賛案内）→ 公開ページでは出さず，「サイトの更新」ページに一覧表示。新歓日程は「昨年度の日程です」と案内。
- お問い合わせフォームが送信できなかった → 用件・お名前・内容を入れたメールを作成して開くように。
- 百年史の枠に「（URL未設定）」と出ていた → 内容紹介とお問い合わせへの導線に。
- お知らせのURLを並び順の番号（`#news-2`）から日付ベース（`#news-20260923-0`）に変更し，記事が増えてもリンクが変わらないように（旧形式も表示可）。
- ページごとにタブのタイトルを設定，説明文（meta description）とアイコンを追加，フッターにSNS・グッズ・OB倶楽部を追加，試作版の帯を削除。
- 6MBのデータを `index.html` から `data.js` に分離。Excel読み込み用ライブラリは「サイトの更新」で使う時だけ読み込むように。
